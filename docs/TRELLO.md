# Quadro Trello (Pessoa 3)

Crie um quadro no Trello chamado **"Fold – Flutter"** com as listas abaixo e copie os cartões. Coloque a **etiqueta** e o **responsável** em cada cartão. Durante o trabalho, mova os cartões da esquerda para a direita. Tire prints do quadro em fases diferentes para mostrar na apresentação.

**Listas:** `Backlog` → `A Fazer` → `Fazendo` → `Revisão` → `Feito`

**Etiquetas:** 🟣 Design · 🔵 Código · 🟡 Documentação · 🔴 Bug

## Cartões

### Planejamento (todos)
- [ ] **Definir a ideia do app**: escolhido: controle de gastos. *(🟡 · todos)*
- [ ] **Listar requisitos**: RF01 a RF05 e RNF01 a RNF02 do README. *(🟡 · Pessoa 3)*

### Design (Pessoa 1) 🟣
- [ ] **Definir paleta de cores e fonte**: verde/vermelho, Roboto.
- [ ] **Desenhar Tela Início**: com saldo, lista e botão +.
- [ ] **Desenhar Tela Início (vazia)**.
- [ ] **Desenhar Tela Novo lançamento**: com variação de erro.
- [ ] **Criar componentes**: item da lista, card, campo, botão.
- [ ] **Montar protótipo navegável**.
- [ ] **Compartilhar link do Figma com a equipe**.

### Código (Pessoa 2) 🔵
- [ ] **Instalar Flutter e criar o projeto**: `flutter create`.
- [ ] **Criar modelo `Transacao`**: `lib/transacao.dart`.
- [ ] **Criar tela inicial com lista**: `lib/tela_inicial.dart`.
- [ ] **Criar formulário com validação**: `lib/tela_adicionar.dart`.
- [ ] **Calcular saldo, entradas e gastos**.
- [ ] **Salvar dados no celular**: `shared_preferences`.
- [ ] **Apagar com arrasto + desfazer**.
- [ ] **Escrever testes automáticos**: `flutter test` passando.
- [ ] **Testar no celular/emulador**.

### Documentação (Pessoa 3) 🟡
- [ ] **Escrever README**: problema, funcionalidades, como rodar.
- [ ] **Manter este quadro atualizado**.
- [ ] **Preparar roteiro da apresentação**.
- [ ] **Montar slides** com prints do Figma, do app e do Trello.

## Dicas para o quadro parecer profissional

- Use **datas de entrega** nos cartões.
- Use **checklists** dentro dos cartões grandes (ex.: "Criar formulário" → campo descrição, campo valor, categoria, validação).
- Comente nos cartões quando algo for decidido ("decidimos não ter edição, só apagar").
- Na apresentação, mostre a lista **Feito** cheia.
